# 국고채·통안채·CD 금리 대시보드 — 설계 문서

- 작성일: 2026-07-27
- 작성자: Claude Code (superpowers:brainstorming)

## 1. 목적

한국은행 ECOS(경제통계시스템)에서 매일 공시하는 채권/단기금리 데이터를 매일 자동으로 수집하여 저장하고, 추세를 시각화한 공개 대시보드를 제공한다. 매일의 추세는 AI(OpenRouter)가 한국어로 자동 해설한다.

## 2. 대상 지표

| 구분 | 만기 |
|------|------|
| 국고채 | 3년, 5년, 10년, 20년 |
| 통안채(통화안정증권) | 1년 |
| CD금리 | 91일 |

총 6개 시계열을 매일 수집한다.

## 3. 전체 아키텍처

```
[한국은행 ECOS API]           [OpenRouter API]
        │ 매일 오후 5시 자동 호출     │ 매일 요약 요청
        ▼                          ▼
   ┌───────────────────────────────────┐
   │  Vercel Cron → API Route          │
   │  (매일 오후 5시(KST) 1회,          │
   │   수집+저장+AI요약 실행)           │
   └───────────────────────────────────┘
                  │
                  ▼
   ┌───────────────────────────────────┐
   │  Supabase (Postgres)               │
   │  - bond_yields (일자별 금리 원본)    │
   │  - daily_summary (일자별 AI 해설)   │
   └───────────────────────────────────┘
                  │
                  ▼
   ┌───────────────────────────────────┐
   │  Next.js 대시보드 (공개 페이지)      │
   │  - 추세 그래프 + 오늘의 AI 해설      │
   └───────────────────────────────────┘
```

- 프론트엔드/백엔드: Next.js (Vercel 배포)
- 데이터 저장소: Supabase (Postgres)
- 자동 실행: Vercel Cron Job → Next.js API Route (`/api/cron/update-rates`), 매일 한국시간 오후 5시 실행 (해당 시각에 한국은행이 대상 지표들의 당일자 금리 업데이트를 완료하기 때문)
- 외부 데이터: 한국은행 ECOS Open API (`StatisticSearch`)
- AI 해설: OpenRouter API (모델은 구현 시 비용/품질 고려하여 선정)

## 4. 데이터 모델

### `bond_yields`

| 컬럼 | 타입 | 설명 |
|------|------|------|
| date | date | 금리 공시 일자 |
| instrument | text | 예: `treasury_3y`, `treasury_5y`, `treasury_10y`, `treasury_20y`, `msb_1y`, `cd_91d` |
| yield_pct | numeric | 금리(%) |

- Primary Key: (date, instrument)
- 동일 (date, instrument) 재수집 시 upsert(덮어쓰기) — 한국은행의 사후 수정치 반영.

### `daily_summary`

| 컬럼 | 타입 | 설명 |
|------|------|------|
| date | date (PK) | 해설 대상 일자 |
| summary_text | text | AI가 생성한 한국어 해설 |

## 5. 화면 구성 (단일 페이지)

- 상단: 지표 선택 체크박스 6개 (국고채 3/5/10/20년, 통안채 1년, CD금리 91일), 기본값 전체 선택
- 기간 선택: 1개월 / 1년 / 5년(기본값) / 전체
- 중앙: 선택된 지표들의 꺾은선 추세 그래프
- 하단: "오늘의 AI 해설" 박스
- 최하단: "마지막 업데이트: YYYY-MM-DD HH:mm" 표시
- 접근 권한: 로그인 없이 누구나 볼 수 있는 공개 페이지
- 다크모드: 화면 우측 상단에 라이트/다크 전환 버튼 제공. 기본값은 접속 기기의 시스템 설정(라이트/다크)을 따르고, 버튼으로 수동 전환 시 브라우저에 선택값을 기억(로그인 불필요)

## 6. 오류 처리

- ECOS API 호출 실패: 해당일 데이터는 건너뛰고 직전 데이터 유지. 화면에 "오늘자 업데이트 실패, 마지막 업데이트: OO일" 표시.
- OpenRouter 호출 실패: 그래프는 정상 표시하고, 해설란에 "오늘의 해설을 준비하지 못했어요" 표시.
- 주말/공휴일 등 정상적으로 데이터가 없는 날: 에러가 아닌 정상 상황으로 처리(조용히 스킵).

## 7. 테스트 계획

1. 자동 수집 작업 수동 실행 → ECOS 원본 값과 Supabase 저장 값 일치 확인
2. 저장된 값 기반 AI 해설 생성 확인 (품질 이상 시 프롬프트 조정)
3. 로컬 브라우저에서 대시보드 UI 동작 확인 (지표/기간 선택, 그래프 렌더링)
4. Vercel 배포 후 실제 URL 접속 테스트
5. 익일 자동 실행 여부 및 데이터 증가 확인

## 8. 보안/데이터 규칙 (CLAUDE.md 준수)

- ECOS API 키, OpenRouter API 키는 모두 `.env` (Vercel 환경변수)에 저장하고 코드에 직접 작성하지 않는다.
- 화면에 표시되는 데이터는 전부 Supabase에서 조회하며, 코드에 하드코딩하지 않는다.
- 배포 전 코드/커밋에 비밀 키나 개인정보가 섞여 있지 않은지 점검한다.
